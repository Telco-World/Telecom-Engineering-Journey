# Git Basics Notes

## What I Have Learned

- A repository is a project tracked by Git.
- A commit is a saved checkpoint of changes.
- A diff shows what changed between versions.
- Green lines mean content was added.
- Red lines mean content was removed.
- The parent commit is the previous commit on which the current commit is based.
- Git does not track empty folders.

## Basic Workflow

Edit file → Save → Commit → Push → GitHub
